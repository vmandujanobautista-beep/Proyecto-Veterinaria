<h1 data-importer="text" align="center">Proyecto Gestión Veterinaria 🩺🐾</h1>

###

<p data-importer="text" align="left">Sistema de gestión para clínicas veterinarias enfocado en recepcionistas que <br>permite la administración de citas, clientes, mascotas, productos y realizar ventas <br>desde el punto de caja y incluye recordatorios y confirmación de citas por email y WhatsApp.</p>

###

<h2 data-importer="text" align="left">Tecnologías 🌐</h2>

###

<p data-importer="text" align="left">- Laravel (PHP)<br>- Tailwind CSS<br>- MySQL<br>- Laravel Breeze</p>
