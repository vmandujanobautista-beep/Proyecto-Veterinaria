

# 🐾Sistema de Gestión para Clínicas Veterinarias🐕

 > Aplicación web desarrollada para facilitar la gestión y administración de una clínica veterinaria.

## Descripción del proyecto
Este proyecto consiste en una aplicación web desarrollada para la gestión y administración de una clínica veterinaria. El sistema permite centralizar la información de los clientes, mascotas, citas, productos e inventario; además, permite el registro de ventas realizadas en la clínica veterinaria. 

La aplicación fue diseñada para una clínica veterinaria ficticia llamada VetCare y permite diferentes niveles de acceso para administradores y recepcionistas. Cada usuario puede acceder a las funciones correspondientes a sus responsabilidades dentro del sistema.
